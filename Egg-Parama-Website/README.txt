EGG PARAMA WEBSITE
==================

Files:
- index.html: Website structure and content
- style.css: Colors, layout, responsive styling, and animations

How to run:
1. Extract this ZIP file.
2. Open the Egg-Parama-Website folder.
3. Double-click index.html to open it in your browser.

Before using for your real business:
- Replace the example phone number and WhatsApp number in index.html.
- Replace the example email and location.
- Update the sample egg prices to your real prices.

This is a static HTML/CSS website. It does not include online payments,
an order database, or a server-side ordering system.
